# Память агента

Один факт — один файл. Индекс — `MEMORY.md`, его агент читает в начале каждой сессии (одна строка на запись, без содержимого).

Формат файла:

```markdown
---
name: короткий-slug
description: одна строка, по ней решают, нужна ли запись
metadata:
  type: user | feedback | project | reference
---

Сам факт. Для feedback и project дальше:

**Why:** почему это важно.
**How to apply:** когда и как применять.
```

Типы:

- `user`: кто владелец, роль, предпочтения
- `feedback`: как работать, поправки и подтверждённые подходы
- `project`: идущая работа, цели, ограничения, которых нет в самих файлах
- `reference`: куда смотреть (ссылки, дашборды, внешние системы)

Не сохранять то, что и так видно из кода и файлов. Если запись устарела, удалить её.
